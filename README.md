## 📖 Guia de Formatação Markdown

O arquivo `.md` (Markdown) é uma linguagem de marcação simples para formatar textos. Aqui estão as principais formas de utilizá-lo:

### 1. Títulos
Use `#` para títulos (quanto mais `#`, menor o título):
# Título Principal
## Subtítulo
### Seção

### 2. Ênfase
- **Negrito:** Use `**texto**` ou `__texto__`.
- *Itálico:* Use `*texto*` ou `_texto_`.

### 3. Listas
- Lista não ordenada: Use `-` ou `*`.
- Lista ordenada: Use `1.`, `2.`, etc.

### 4. Blocos de Código
Para destacar código, use três crases (```):
```javascript
let variavel = "Exemplo";
console.log(variavel);
